# 🚀 GTA 6 24/7 Autonomous Cloud Clipper & Poster

> **100% Free & 100% Cloud-Only.**  
> Runs entirely inside GitHub Actions. Your personal computer does NOT need to be on or connected.

---

## ⚡ How It Works (Cloud-To-Cloud)
1. **Cloud Cron:** GitHub Actions wakes up every 30 minutes in Microsoft's cloud data centers.
2. **Live Detection:** Scans top GTA 6 Twitch / YouTube streamers.
3. **Smart Video Clipping:** Cuts a 45-second high-energy live moment using `streamlink` and `ffmpeg`.
4. **9:16 Vertical Reframing:** Converts widescreen gameplay into 1080x1920 Short with blurred background & centered gameplay.
5. **AI Viral Copy:** Google Gemini 2.5 Flash generates a high-CTR title, description, and hashtags.
6. **Delivery:** Pings your mobile phone via Telegram with the video preview, and saves it to GitHub Artifacts.

---

## 📱 Mobile-Only Configuration (Optional)
In your GitHub Repo:
1. Go to **Settings** $\to$ **Secrets and variables** $\to$ **Actions** $\to$ **New repository secret**:
   - `GEMINI_API_KEY`: (Optional) Free key from [Google AI Studio](https://aistudio.google.com/) for custom AI titles.
   - `TELEGRAM_BOT_TOKEN`: (Optional) Bot token from `@BotFather`.
   - `TELEGRAM_CHAT_ID`: (Optional) Your Chat ID from `@userinfobot`.
   - `TARGET_STREAMERS`: (Optional) Comma-separated list of Twitch/YouTube stream URLs.

## 🛑 Zero PC Requirement
Once pushed, this repository runs 24/7 autonomously in the cloud forever. You can turn off your PC, delete local files, or manage everything from your mobile phone.
